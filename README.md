# Калькулятор (Visual Studio 2022)

Консольное приложение. Считает `+ - * / ^ ()` и унарные функции из DLL в папке `plugins` рядом с текущим каталогом.

Имя функции — единственный экспорт DLL. Имя файла не используется: `funcsin.dll` регистрируется как `sin()`.

## Как запустить

1. Открыть `calculator.sln` в Visual Studio 2022.
2. Сверху выбрать **Debug** и **x64**. Стартовый проект — `calc`.
3. Зелёная кнопка «Запустить» или F5.

Сборка кладёт `calc.exe` в `bin\Debug\`, а DLL — в `bin\Debug\plugins\`. Рабочий каталог отладчика — `bin\Debug`, поэтому программа видит `./plugins`.

## Примеры

```text
16 + 4 * (3 - 1)
24

2^4 + sin(deg(90))
17

ln(-100)
ошибка: ln: аргумент должен быть > 0
```

`sin` — в радианах. `deg` переводит градусы в радианы.

Пустая строка или `exit` завершает программу.

Некорректная DLL, библиотека не с одной функцией (`bad_two.dll`) и отсутствие плагинов не роняют процесс: такая библиотека пропускается, арифметика остаётся доступной. Исключение внутри функции (например `ln` от неположительного числа) перехватывается и печатается как ошибка.
